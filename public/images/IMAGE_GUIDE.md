## How to Save Images

### From Google Maps (Mobile):
1. Open Google Maps → Search "Mana" → Tap Photos
2. Tap the photo you want → tap the three dots (⋮)
3. Tap "Save to device"
4. Rename the saved file to match the filename above
5. Upload to `public/images/` folder

### From Google Maps (Desktop):
1. Open Google Maps → Search "Mana" → Click Photos
2. Right-click the photo → "Save image as..."
3. Rename to match the filename
4. Upload to `public/images/` folder

### Replacing Images:
Just overwrite the existing file with the same filename. The site updates automatically.
